# SAM3.1 + EGM grounding 重构设计

更新日期：2026-09-15。本文记录已确认设计和实施约定；实际部署状态以服务器 `.local/role-grounding-deployment.json` 回执为准。允许可辨认的模糊／远景目标，取消短边 32 px 门槛。

依据：本任务中的明确选择，以及已读取的关联聊天[取消输出截断](chatgpt-conversation://6aa8055c-e030-83eb-84c0-a1ce40e6f6f3)。关联聊天中的建议作为背景，不自动作为决定；冲突处采用用户本次明确反馈：第一版采用 Level 2 targeted local search，同时保持固定类别预算，不采用 adaptive budget。

## 1. 目标与范围

尽可能覆盖图片中的可标实例，为实例生成自然、唯一、有可见依据的 phrase，减少模型能力和置信度排名造成的漏标。

核心原则：**从 consensus-based filtering 改成 role-specialized evidence + disagreement handling。** 模型分别提供发现、定位和语义判断证据，不以模型票数决定对象去留，也不让单个定位模型的失败直接否决已确认对象。

本轮只处理 grounding。不生成 counting QA，不设计 counting-ready／completeness flag，不以某类必须找全作为保留对象的条件。停止搜索不意味着已经找全。

## 2. 已确定的规则

| 项目 | 决定 |
|---|---|
| Grounding 模型 | SAM3.1 处理 category query；EGM-Qwen3-VL-8B 处理 locator query 和 reground；移除 Rex、GroundingDINO 的 grounding 职责 |
| Qwen 职责 | 保留类别提出、描述、OCR／常规视觉审核；分歧时追加 targeted semantic adjudication，不作为第三个投票 grounder |
| 候选入口 | 从挑选少量易描述目标改成类别盘点、逐类实例发现；caption 作为参考，不作为类别资格或完整性证明 |
| 最终框 | 同一实例默认采用经验证的 SAM 框，范围分歧交视觉审核；没有 SAM 框的合格 EGM-only 实例记录真实框来源 |
| SAM 漏检 | EGM 找到的对象经额外审核后允许加入，不要求凑齐两个 grounder 支持 |
| 可标对象 | 允许可辨认的模糊／远景目标；严重遮挡或截断可以跳过；不能编造不可见属性或边界 |
| 尺寸 | 已取消短边 32 px 门槛；现有面积比例限制没有因此取消 |
| 表达 | 自然、唯一且有可见依据即可；不强制至少 8 词、两个区分线索；重复外观允许通过空间位置区分 |
| 搜索 | Full-image + category-specific targeted local search；不做全图固定网格乘所有类别的穷举 |
| Category query | 确定 canonical category query 后保持不变；不生成同义词改写，不通过改词扩展类别 |
| 预算 | 每类相同基础搜索机会、相同额外搜索上限；实例数量和新增产量不能增加配额 |
| 保留 | 已确认对象持久保留；phrase unresolved 不删除对象；所有合格结果全部输出，不做 Top-30 截断 |

“已确认对象持久保留”针对通过对象验证的实例，不意味着所有 raw detections 都被自动认定正确。对象记录、框版本、phrase 版本和审核证据分开保存，phrase 状态不能级联删除对象。

## 3. 处理流程

1. Qwen 基于原图提出有可见依据的类别和必要的目标线索，为每个类别建立固定的 canonical query。避免先挑高置信实例，再用实例名单限制类别搜索。
2. 每个类别都获得一次基础 full-image SAM 搜索。先完成各类基础机会，再执行额外搜索，避免某个产量高的类别先占用所有计算。
3. SAM 检测进入逐类实例池，经对象审核与去重后建立稳定 object ID；EGM 对已有 locator 做独立定位，与实例池进行身份匹配。
4. 根据类别内的漏检证据建立 targeted search 请求，预算允许时，对指定区域使用相同 category query 调用 SAM。
5. 将局部框映射回原图，跨视图去重、验证范围并更新对象集合。EGM-only 候选不能因 SAM 未匹配而自动丢弃，也不能未经审核直接放行。
6. 为确认对象生成 phrase，在原图上下文中检查事实与唯一性；允许简短的空间描述，不为凑线索编造细节。
7. EGM 仅接收原图和最终 phrase 做 reground。正常成功走通过路径；失败进入针对性语义裁决，必要时改写并重新验证。
8. 对象层输出所有确认对象；phrase 层输出通过的表达，单独保存 unresolved／需要修订的表达与原因。显示分页不影响数据保留。

局部补查可能由后续 locator／reground 的差异触发，因此执行顺序允许有限回流，不能假定 discovery 阶段一次结束后永不更新。新发现的同类对象可能使已有 phrase 变得歧义；需要重新检查受影响表达，尤其是位置／顺序指代，但保留 object ID 和已有历史。

## 4. Reground 与 A-vs-B semantic adjudication

定义：A 为当前已确认的目标对象及冻结框版本；B 为 EGM 根据当前 phrase 返回的定位结果。A 默认来自 SAM，也可能是已通过审核的 EGM-only 对象。

EGM reground 不读取 A 的坐标、答案 crop 或编号 overlay，避免把给定答案后的匹配当作独立定位。Qwen 裁决则明确观察 A、B、其他同类对象及原图上下文；它承担语义判别，不是重新生成任意框。

### 正常路径

**EGM reground success → 正常通过。** 此处成功指恢复 A 的身份与合格范围，同时常规事实、语法和唯一性检查成立，不因为成功再追加一轮分歧裁决。EGM 只返回一个框本身不是唯一性证据。

### 分歧路径

**EGM reground failure → Qwen targeted A-vs-B semantic adjudication。** 检查：phrase 是否真实描述 A、是否也适用于 B 或其他实例、是否足以唯一确定 A，以及 B 是否比 A 更符合表达。

| 裁决结果 | Phrase 处理 | Object 处理 |
|---|---|---|
| 明确、可见证据支持 phrase 唯一指向 A | 放行，记录 `semantic_adjudication` 通过路径与 EGM 分歧证据 | 保留 A，不把 EGM 原始失败改写成成功 |
| A、B 或其他对象都符合，存在 ambiguity | 针对歧义 rewrite，再做正常验证和 reground | 保留 A，改写不更换目标 |
| Phrase 不符合 A，或 B 明确更符合 | 标记当前版本需要修订；可依据 A 的可见事实改写并重新验证 | 保留 A，不偷偷改成 B；B 是否是新增合格对象另行处理 |
| 证据不足、无法确定，或修订预算耗尽仍无可靠结论 | 标记 `unresolved`，不进入通过的 box–phrase 集合；运行时保留历史，最终仅保留当前原文及简短原因 | A 持久保留 |

Qwen 明确支持 A 必须回答竞争对象与可见依据，不能只重复第一次“通过”结论。其结果是语义证据，不包装成第二个独立 grounder 的赞成票。

如果 B 与 A 是同一物体但框范围不同，优先归入范围分歧，不能把几何阈值失败自动解释成语义错误。旧 IoU ≥0.5、面积比 ≤1.25 需要结合新框角色校准；身份匹配与范围质量分开记录。

EGM 没有返回有效框时，不编造 B：使用原图、A 和其他同类对象评估表达，并记录 `no_valid_locator_box`。服务故障、OOM 或请求中断属于执行错误，走重试／恢复，不冒充模型已完成的语义失败。

对象是否成立、phrase 是否成立、定位模型是否做对是不同状态。原始 grounding 结果不可被裁决覆盖；通过路径可以是 `reground` 或 `semantic_adjudication`，不能都伪装成 reground 成功。

## 5. Level 2：按类别、有证据的局部补查

补漏单位为 `(image_id, category_id, region)`。某个类别在一个区域疑似漏检，只对该类别和区域补查，不扩展成对整张图所有类别重新搜索。

允许的触发信号：

- EGM 的 locator／reground 返回未匹配 SAM 实例池的有效候选框。
- Qwen 基于当前图像给出可定位的区域及同类对象的可见线索。
- 同类实例的空间分布出现疑似 gap，并能指出具体检查区域。
- 远景区域存在重复类别的可见迹象，可能在全图推理尺度下被漏检。
- 同一类别的跨视图结果出现新的候选或明显差异，可作为剩余配额内的补查线索。

这些信号均是搜索线索，不是新增对象存在的证明。空间 gap 不能推出那里必有对象；Qwen 的猜测也不能直接生成有效标注。每个触发记录类别、区域、来源和理由；缺少可定位区域或可见依据时不发起泛化盲搜。

局部搜索始终使用原 canonical category query；只改变观察区域，不改类别语义。Crop 是发现工具，最终框和表达始终以原图为参照：

- 保存裁剪坐标及缩放变换，把 bbox／mask 正确映射回原图。
- 跨视图合并同一物体，避免把重复框当新增实例。
- Crop 边缘截断不等于物体本身在原图中被截断；需要扩展观察范围或回到原图核对完整性。
- “最左边”“第二根”等表达在原图和明确参照集合中验证，不能用 crop 局部顺序或检测列表顺序代替。

## 6. Cross-role discrepancy detection

SAM 与 EGM 的差异用于诊断，不重新组成传统 consensus。

| 差异 | 含义与处理 |
|---|---|
| EGM 框未匹配 SAM 实例 | 疑似 SAM 漏检、EGM 错位或范围偏差；触发类别内局部补查／审核，不直接判任何模型正确 |
| 两者同一对象但范围不同 | 范围审核；默认保留合格 SAM 框，不平均两个框来掩盖问题 |
| 最终 phrase 指向 A，EGM 定位到 B | A-vs-B 语义裁决；若 B 疑似新对象，可另外产生该类别的补查请求 |
| SAM 找到多个实例，EGM 只定位一个 | 两者职责的正常差异，不能据此删除其他 SAM 实例 |

由 EGM 框引导的 SAM 局部搜索有依赖关系，不能作为第二份独立发现票。也不能将两类模型的 confidence 数字直接平均成统一可信度。

## 7. Category-level fair budget + no output truncation

每个已确定类别的搜索配额采用同一规则：

`B(c) = 1 次 full-image 基础搜索 + 最多 K 次 targeted local search`

K 是全体类别共享的固定配置上限，具体值在实现前的小批成本测试中确定；不随当前实例数、最近新增数量或“产量”提高。局部搜索仅在有证据时消耗机会，公平上限不意味着无证据也必须用完配额。

调度原则：

1. 保证所有类别先有相同的基础搜索机会。首次找到零个实例不取消该类别的剩余补查资格。
2. 对有补查证据的类别轮转调度；每次执行受本类别相同的 K 上限约束。
3. 类别内合并重叠、重复区域；新增框可更新证据，但不能刷新配额或形成无限发现循环。
4. 第一版不按检测数量奖励配额，也不把未用配额自适应转给产量高的类别；不构造复杂 coverage score 或估计完整性。
5. 预算计量为搜索调用／视图机会，不是最多找到多少个 box。语义复核与 phrase rewrite 使用独立、有限的预算，不能消耗其他类别尚未获得的基础搜索机会。
6. 预算耗尽停止继续发现，记录未处理证据；已确认对象全部保留，待完成审核的候选保留 pending 状态，不伪装成完成或因全局时间限制静默删除。

只在有证据时选择 crop 属于 targeted search；给类别动态增减配额属于 adaptive budget。第一版采用前者，不采用后者，两项决定不冲突。

取消最终 Top-30 和 review 数据截断；旧 proposal／promotion 上限也不能在中途把已发现的合格实例裁掉。批处理与分页可以控制内存和展示量，不能改变保留集合。有限搜索不能保证找全，本设计不声明 category completeness。

## 8. 数据与运行改造范围

建议最小记录分层，具体字段名在实现时确定：

- Category：固定 query、基础搜索完成状态、局部搜索已用次数、待查区域及停止原因。
- Object：稳定 ID、原图坐标、框版本／来源、对象审核状态、跨视图匹配与证据。无 phrase 或 phrase unresolved 不删除确认对象。
- Phrase：关联 object ID／框版本、文本版本、常规审核、EGM 原始结果、裁决结论、通过路径、rewrite 历史、unresolved 原因。

| 部分 | 必要改造 |
|---|---|
| 请求路由 | SAM 接 category；EGM 接 locator 和最终／改写后的 phrase；按各自请求子集核对完成情况 |
| EGM adapter | 固定官方模型版本，核对坐标、答案解析、图像处理和推理预算；不继承 Rex 的 64-token 限制 |
| 聚合／promotion | 用类别实例池与身份匹配替换至少两个 grounder 支持；SAM-only 实例可独立进入对象验证 |
| 框选择／修复 | 默认合格 SAM 框，EGM-only 有独立审核分支；记录身份和范围差异，不依赖票数 |
| 局部搜索 | 固定 category query、证据触发、类别公平配额、坐标映射、跨视图去重、有限回流 |
| 表达与审核 | 去除最小词数／双线索硬门槛；实现正常路径、A-vs-B 裁决、rewrite 和 unresolved |
| Finalization | 分离对象与 phrase 保留；去除 Top-30；支持语义裁决通过，不能沿用所有 reground 布尔值必须 true 的旧合同 |
| 缓存／checkpoint | 请求角色、query、view、模型版本、框／phrase 版本、搜索预算和裁决阶段纳入身份；恢复不能重置预算或重复创建对象 |
| 模型服务／调度 | 更新 worker 注册、环境、常驻服务、阶段依赖与日志；新语义采用新 run，不伪造与旧断点等价 |

不重写无关的图片工具、可靠存储或全部 OCR 实现；按新流程更新其接口和调用依赖。

## 9. 实现与验收要点

以下列出验收范围；实际执行状态由对应源码版本的测试日志和部署回执记录：

- 某类找到很多实例，另一类找到零个时，两者基础机会和 K 上限仍相同；恢复执行不重置计数。
- SAM-only 实例不会因缺少第二个 grounder 被删除；EGM-only 实例经过额外审核并记录来源。
- 裁决明确支持 A 可放行 phrase，同时保留 EGM 失败事实；ambiguity 触发 rewrite；unresolved 不删除对象。
- 改写不切换 object；新增同类实例后，受影响的空间指代表达重新检查。
- 没有合法 B、服务失败和真实定位分歧分别处理。
- 一张图超过 30 个合格实例时全部保存，review 分页不影响数据；旧中间 cap 不再隐藏裁剪实例。
- 每次局部补查保持同一 category query，只搜索目标类别；坐标还原、crop 边界和跨视图去重正确。
- 不添加 counting 功能、完整性门槛、固定全图网格扫描或按实例产量调整预算。

小批对比应使用相同原图，检查实例覆盖、标注错误、空间表达歧义、unresolved 比例及每类搜索调用量。对象数量增长本身不证明质量提高；定位成功率也不能代替独立标注质量检查。

剩余的是实现参数：每类 K、裁剪 padding、区域合并方式、匹配／范围阈值、rewrite 上限、EGM 推理预算与资源配置。它们不是尚未决定的架构分支，实施前固定配置并通过小批测试校准；本次不擅自宣称已完成该测试。

## 实施时澄清：最终归档保持节省空间

用户询问保留对象是否会破坏原有空间策略。实施采用最小交付记录：通过的 box–phrase、所有确认对象的原图引用／坐标／类别／phrase 状态，及需要复核的当前 phrase 和简短原因。最终不保留完整模型回答、全部历史、mask、crop、临时视图或 unresolved 的额外图片。完整操作记录仅服务运行时恢复；最终归档校验成功后沿用原有清理流程。对象持久保留不意味着中间计算证据全部永久保留。


## 执行阶段与基础设施适配（2026-09-14）

保留启动入口、GPU 归属、任务领取、图片级租约、跨节点发布／恢复与完成后清理机制，不固定保留旧的 18 个阶段。新版由 `src/routes/role_schedule.py` 统一定义阶段名称、职责和顺序；CLI、GPU worker、进度显示、跨节点断点都读取它。旧 aggregate／align／promote 等阶段不再作为新版占位阶段执行。

当前默认两轮 rewrite，对应 25 个执行阶段：类别清单 → SAM 类别发现＋EGM locator 检查 → 对象审核 → 首次局部补漏 → 补漏对象审核 → OCR → phrase 生成 → EGM reground → 语义裁决；每轮依次执行局部补漏、对象审核、唯一性复核及改写、EGM reground、语义裁决；最后审核末轮新增对象、补做 OCR 与描述生成（含预算内的剩余改写）、执行收尾 EGM reground、复核 phrase、导出对象状态、生成审核图。收尾 reground 保留 A-vs-B 证据用于裁决，但不再扩展新候选链。无待处理证据的补漏阶段直接完成，不产生额外模型调用。

第一版默认每类别一次全图 SAM、至多两次初始 EGM locator 检查、至多两次局部 SAM；局部预算跨全部轮次共享，不因检测数量增加。每对象正常 reground 属于该对象表达验收。已确认实例不截断。EGM-only 新对象额外进行一次不提供 locator 假设的全图对象审核。

新版采用独立断点合同 `role-grounding-storage-v1`，与旧阶段合同不混用。恢复时保留对象 ID、框版本、phrase 状态、调用证据和预算；批次路径或 Qwen HTTP 地址变化不使语义缓存失效。新模型、prompt 或语义策略变化仍要求新 run。

最终最小交付：原有 verified box–phrase 和审核图；另增加所有已确认对象索引、unresolved 当前表达及简短原因、类别搜索次数摘要。以上均为文本，不为 unresolved 额外生成图片。完整调用回答、历史、mask/crop 和工作目录仍在归档校验后清理。


## 审计补充（2026-09-14，候选实现，未部署）

- 标准紧框贴着物体四边不是截断；矩形内的少量背景、手指和佩戴接触不应导致拒绝。严重原图遮挡、错误位置和明显漏掉可见主体仍拒绝。此 prompt 校准待真实 GPU 复测，不声明质量已通过。
- 恢复身份包含 caption、图片 ID／尺寸及 grounding adapter、图像传输和几何代码；换节点的 HTTP 地址和组批路径不改变身份。重复、外来图片或非法阶段的 checkpoint 在写入前拒绝。
- 最终归档前逐项核对对象、phrase 状态与文字、裁决结果和搜索摘要与原状态一致；归档后通过每图 object／unresolved 计数以及文件哈希发现丢失。只增加小型文本计数，不保留完整运行历史。
- 上下文超长与服务错误是运行故障，不作为语义 unresolved 缓存；改写输入只带上次 phrase 与必要原因，不回传 EGM 长推理和完整历史。
- 部署需要与待部署代码、私有配置及 infra 哈希绑定的 Linux 测试和 GPU 验收记录；旧日志不能替改过的代码放行。


## 图片抽样模式（2026-09-15）

日常启动入口提供 `--sample-size 1962` 和 `--sample-size 100`，新 run 默认 1962 张。100 张使用原有 `sample_seed`（当前 42）从同一清单随机抽取，选中图片和任务分区写入 plan。已有未完成 run 的续跑或节点加入沿用原选择，不重新抽样；显式数量与保存的选择不一致时拒绝启动，不修改原 run。原 run 完成并归档后可以切换数量。

该参数仅决定输入图片集合，不改变模型、阶段、类别预算、GPU 分配、任务领取、跨节点恢复或归档规则。专门配置的小型审计清单在省略参数时仍运行清单全部图片。私有启动与配置代码保留在 `.local`，不上传 GitHub。
